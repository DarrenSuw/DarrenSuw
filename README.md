### 🚀 Featured Projects & Research

#### 🦠 Malware Analysis Research (Ongoing)
Working as a Research Assistant under **Asst. Prof. Ts. Dr. Teh Jia Yew** at the School of Computing and Data Science, Xiamen University Malaysia. Investigating malware detection utilizing **Dynamic Analysis** and **Machine Learning** techniques, focusing on evaluating model robustness against adversarial attacks and analyzing evasion thresholds to fortify security infrastructure.

#### 📊 WhatIf Forecaster (Ongoing)
A decoupled **AutoML SaaS platform** utilizing FastAPI and FLAML to automate model selection. Features a highly reactive **Next.js** dashboard with interactive forecasting simulations, real-time training logs streamed via SSE, and local feature influence analysis using **SHAP**.

#### 📄 Resume Forge (Ongoing)
A web-based ATS optimization platform. Engineered robust **NLP/OCR pipelines** to extract and structure unstructured document data, integrated with **Gemini 2.5 Flash** to power an autonomous chatbot for context-aware cover letter and resume rewriting.

#### 🤖 AskA Maintenance Automation
An automated infrastructure dispatch system commissioned by XMUM IT Services. Built alongside Data Science and EEE students. Leverages **n8n workflows**, intelligent email routing, and a custom-trained **LLM conversational agent** to triage requests and optimize workflow efficiency.

#### 🃏 Blackjack Q-Trainer
A professional-grade **Reinforcement Learning** simulation. Trained a Q-Learning agent over 200,000 episodes featuring dynamic bankroll sizing via the **Kelly Criterion**. Built a phase-guarded **Pygame** UI, generating data-driven policy heatmaps using **NumPy** and **Matplotlib**.
